# LPY 職業治療個案檔案索引（私隱安全版）

這是個案檔案索引的程式原始碼備份。GitHub 版本只包含程式及空白 Excel 範本，不包含任何真實個案姓名、標記、增刪紀錄或備份資料。

## 主要功能

- 紅、橙、藍三組固定檔案位置，每組 31 個位置
- 姓名及 C／H／E／D／V 標記搜尋
- 單一及批量新增、修改與刪除
- 離線本機儲存（IndexedDB）及歷史版本
- 完整 `.lpybackup` JSON 備份匯出、預覽及安全還原
- A4 橫向 Excel 紙本輸出及個案查詢工作表

## 私隱規則

1. 不要把 `.lpybackup`、Excel 匯出檔或其他真實個案資料加入 GitHub。
2. Repository 應維持為 Private（私人）。
3. GitHub 只儲存空白程式；日常個案資料只存於使用中的裝置及由使用者自行保管的備份檔。
4. 分享、轉移或維修裝置前，先確認瀏覽器資料及下載資料夾沒有個案資料。
5. 如懷疑資料曾被錯誤提交，請立即停止分享 repository；只刪除最新檔案不足以清除舊提交歷史。

## 本機使用

需要 Node.js 22.13 或以上版本及 pnpm。

```bash
pnpm install
pnpm dev
```

正式建立版本：

```bash
pnpm build
```

如另行部署，可複製 `.env.example` 並把 `NEXT_PUBLIC_SITE_URL` 設為該網站的正式網址。不要在環境檔案內加入個案資料。

本 repository 已提供 GitHub Pages 自動部署設定。GitHub 只接收空白程式；使用者在裝置內輸入的個案資料不會因部署而上傳。

首次開啟會顯示 93 個空白位置。個案資料在使用期間只儲存在該網站來源對應的瀏覽器儲存空間內，不會自動上傳至 GitHub。

## 備份說明

- `.lpybackup`：完整復原用，包含姓名及操作紀錄，必須視作機密個案資料。
- `.xlsx`：紙本及人工查閱用，也可能包含個案姓名，不能提交到 GitHub。
- 建議把備份存放在受密碼或裝置加密保護的位置，並定期測試匯入。
